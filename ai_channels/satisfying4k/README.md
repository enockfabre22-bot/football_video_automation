# Chaîne IA « satisfying4k »

Dossier partagé par les animations IA de cette chaîne (format long 16:9 et format Short 9:16) :
un seul cahier des charges, un seul historique créatif → l'IA évite les répétitions entre les deux formats.

```
brief/brief.md      cahier des charges (à remplir)
brief/examples/     codes d'animations existantes (.cpp, .h) — 3 à 5 fichiers maximum
brief/images/       captures d'écran de référence (.png / .jpg) — 4 à 8 images maximum
```

Conseils :
- Les exemples et images sont envoyés à l'IA à chaque création (mis en cache pour limiter le coût) :
  choisis les plus représentatifs plutôt que beaucoup de fichiers.
- Les captures sont automatiquement réduites à 1024 px de large avant envoi.
- Les codes d'exemple peuvent avoir leur propre boucle `main()` : l'IA s'en inspire pour le style
  et les mécanismes, mais écrit toujours ses scènes selon le contrat `anim_runtime.h`.
- La musique de fond est prise dans `assets/music/satisfying4k/` (fichiers .mp3/.wav libres de droits,
  utilisables en monétisation, ex. YouTube Audio Library).
